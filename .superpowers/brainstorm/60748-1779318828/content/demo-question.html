Interactive Demo — What does it actually do?

After all permissions are granted, Luma runs an interactive demo. What should that demo show?

A

Scripted walkthrough

Fixed sequence: Luma speaks a preset script, its blue cursor points to real UI elements on screen (menu bar, current app), explains what it sees, then says "Try asking me something." Simple, predictable, always the same.

B

Dynamic demo using live screen context

Luma scans what's currently on screen, picks 2–3 real UI elements visible right now, narrates what it sees ("I can see you have Finder open…"), points the cursor at them, then invites a command. Different every time.

C

Skip the demo

No demo at all. Once permissions are granted, Luma just says "You're all set — try holding Ctrl+Option and speaking a command." Fast and no-nonsense.
